Put the game data of Crusader: No Regret in this folder (it is not distributed
with the port). Either:

  - the files of an install of the game, English 1.06
    (STATIC, USECODE, SOUND, FLICS, CRUSADER.EXE...), or
  - the .iso image of the CD, English 1.06: the game extracts it
    here on its first launch.

Then run the game. See README.md.
